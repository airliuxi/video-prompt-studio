连接与备份

AI 扩写接口

直接从浏览器请求 OpenAI 兼容的 Chat Completions API。服务需允许当前页面的跨域请求。

基础地址会自动补全 /chat/completions。公网地址使用 HTTPS；本机与局域网地址允许 HTTP。
三种设置都会严格校验结果；不合格时自动请求修正一次。OpenAI 及兼容结构化输出的接口建议选 json_schema；接口报 400 错误时改回「不发送」。

GitHub Gist 备份中心

上传只包含历史、收藏、自定义词条和界面选项，绝不包含 API 设置或密钥。新建为 Secret Gist（不公开列出，持有链接的人仍可访问）。

本地历史

编辑时自动保存会持续更新同一条记录；点击「存入历史」或 Ctrl/Cmd + Enter 会固定为独立一条。普通记录保留最近 50 条，收藏的记录置顶且不计入上限、不会被自动清理。重载后会替换当前槽位。

# Video Prompt Studio

直接双击 `index.html`，或将它上传到任意静态托管服务。应用只有这一个运行文件，无 npm 安装、无构建、无自定义后端。样式内置，DM Sans / Noto Sans SC 和固定版本 Lucide 从公共 CDN 加载（Lucide 带 SRI 完整性校验，文件被篡改时浏览器会拒绝执行）；CDN 不可用时仍可通过文字操作核心功能。

## 1.4 更新

**提示词质量**

- 新增第七维「声音与对白」。Sora 2、Veo 3 等能生成声音的平台会导出 `Audio:` 一行，对白写在引号内；不生成声音的平台自动略过，并在输出区提示。
- 目标平台改为按各平台的官方写法分别导出，不再使用自创的 `[镜头语言]` 方括号格式和强制追加的 4K 质量尾缀：
  - 可灵、即梦 / Seedance、通义万相、Luma：主体 → 动作 → 场景 → 镜头 → 风格，写成自然语句。
  - Sora 2、Veo 3：先写场景段落，再分行列出摄影、风格和声音。
  - Runway：镜头运动放在最前，只用正向描述。
  - 海螺（MiniMax）：已应用摄影机方案时，追加官方方括号运镜指令，例如 `[Push in]`。
  - Midjourney Video：只写动作与运镜，并附 `--motion low` / `--motion high`。
- 每个平台单独说明是否有负向字段、能否生成声音。Runway（约 1000 字）和可灵（约 2500 字）超出字数上限时只提示，不阻止复制。
- 新增「图生视频」开关：只导出动作、运镜与声音，外观与场景交给参考图。Midjourney Video 自动启用。
- 移除无效的 `--motion 5` 词条；摄影机英文描述改用分号分隔，避免出现「slow, smooth dolly in」这类逗号歧义。

**AI 扩写与导演规划**

- 「仅扩写」「AI 编排」「导演规划」都会带上你已经填写的各维度、目标平台与图生视频设置，让 AI 在原稿基础上完善，而不是推倒重写。
- 扩写的系统提示词补充了各维度的写作要求：中英内容对等、不凭空编造对白、少用 8K / masterpiece 这类空泛的画质词。
- 先从回复中提取 JSON，再严格校验：可以接受 Markdown 代码围栏、`<think>` 推理段落或前后多余的说明文字；字段校验仍然严格。校验不通过时，会把 AI 的原回复和错误原因发回去，自动请求修正一次。
- 「输出格式约束」新增 `json_schema` 结构化输出（OpenAI 等支持的接口推荐使用），共三档：不发送 / `json_object` / `json_schema`。
- 快速配置新增阿里云百炼与 OpenRouter；OpenAI 的示例模型改为 `gpt-5-mini`。局域网地址（如另一台电脑上的 Ollama）可以使用 HTTP，且无需 API Key。
- 单次等待上限放宽到 120 秒，导演规划每步 180 秒，方便推理型模型。

**历史与人物**

- 编辑停顿时，自动保存会持续更新同一条记录，不再每停顿一次就新增一条；点击「存入历史」才固定为独立一条。
- 收藏不计入「最近 50 条」上限，不会再被自动清理。收藏最多保留 200 条。
- 人物自动识别补充了大量常用称谓与代词（他、男生、妈妈、老师、women、he 等），并排除「其他」这类误判。
- 人物方案的依据改存短哈希，不再在每条历史里重复保存整份 JSON；旧记录仍可识别。修改「声音」不会让人物方案失效。

**维护**

- 代码已格式化为常规多行风格；测试通过显式标记定位，不再依赖某一行代码的写法。
- 基础字号整体调大 1px。


## 1.3 新增：人物表演与行为逻辑

人物扩写优先写清「为什么行动、朝哪里看、哪只手接触什么、动作结束后物体在哪里」，减少无动机的表情、转头、走动和摆拍。身份、发型与服装等明确约束会被保留，不用堆砌皮肤毛孔或画质词代替行为设计。

- 顶部展开「人物表演与行为逻辑」，可选择自动判断、人物表演或通用场景。只写人名且自动判断不准确时，可强制选择人物表演。
- 默认稳妥策略：十秒内安排一个核心任务及其准备、接触和收尾，通常3–5个时段；可选择保留原述复杂动作并要求指出难点。
- 可选填写固定身份/服装，以及起始姿态、道具位置和行为目的。它们作为下一次生成的约束，不会直接重写当前提示词。
- 人物导演规划分两步：先生成方案，再由同一配置模型在独立提示下复核因果、反应、视线、身体平衡、左右手、接触和支撑交接。会产生两次API请求，每步最长120秒，可取消；任一步失败均不替换原稿或旧候选。
- 方案中的人物因果表与时间轴逐段对齐，显示触发/目的、实际动作与结果状态，同时展示起始空间关系、身份锚点、连续性约束、文本复核说明和剩余难点。
- 人物身份锚点统一写入主体槽位，避免方案内出现两个互相冲突的人物描述。完整因果表与复核说明用于审阅，不整段塞入生成提示词；导出只保留当前设定、必要连续性与分段动作。
- 整套采纳同步人物设定。仅采纳相机或时间轴不强行替换现有人物身份。修改人物、摄影机、动作或人物约束后，原逻辑表会转为参考，不再混合新动作与旧因果说明，也不继续向导出追加旧人物约束。
- 内置「人物放杯 · 10秒」示例：双手扶住杯身，杯底露出；先落杯并转移支撑，再松手、收手，最后看窗外。内置示例不冒充AI实时复核结果。
- 人物数据随草稿、历史、JSON与白名单备份保存；旧版记录缺少这些字段时自动补齐默认值。

文本复核不等于视频验证，不能保证生成模型的人脸、手指或物理交互正确。若视频平台支持图生视频，可考虑用干净、清晰的人物首帧固定外观与起始构图；动作提示继续关注具体动作。参考：[Runway 图生视频指南](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)。

## 1.2 新增：一句话导演规划

1. 在顶部填写画面描述，可写主体、动作、场景、情绪和明确的摄影偏好；不必自己先选相机。
2. 设置总时长与是否连续长镜头。默认 10 秒；它们与下方时间轴设置同步。
3. 点击「AI 导演规划」。一次请求返回各维度双语扩写、摄影机与镜头推荐、双语时间轴，以及相机选择与节奏安排的理由。
4. 在「导演建议」中先审阅。可展开各维度内容；建议语言跟随输出区的 English / 中文对照切换。
5. 点击「采纳整套方案」同步填入所有编辑区；也可只采纳相机或只采纳时间轴。原稿先存入历史。单独采纳时间轴后请核对它与现有摄影机是否一致。

「沿用当前摄影机方案」启用时，AI 必须保留当前八个摄影机选项，否则整份候选方案被拒绝。未启用时，模型根据描述自行推荐；明确的创作约束会在请求中优先说明。应用时镜头文本由已验证的选项统一生成，避免界面显示 35mm、输出却写 85mm。

候选方案仅在本机保存，刷新后仍可查看。生成过程中编辑草稿，迟到的响应不会覆盖新编辑；生成后改变描述、摄影机或时长会让候选方案过期并禁用采纳。完全恢复原来的输入可重新采纳。已采纳的规划说明随草稿、历史、单条 JSON 与备份保存，手动改动后只作原方案参考。候选方案本身不会进入云端备份。

原来的「仅扩写各维度」和时间轴「AI 编排」仍可单独使用。导演规划最长等待 120 秒，可取消；API 需配置你自己的兼容服务与模型。严格校验通过前不改动现有各维度、摄影机或时间轴，失败可直接重试。

## 1.1 新增：摄影机方案与时间轴

- 摄影机参考：ARRI ALEXA 35、ALEXA Mini LF、Sony VENICE 2、FX3、Blackmagic Pocket 6K Pro、16mm 胶片摄影机，也可以不指定机身。
- 可组合 24 / 35 / 50 / 85 / 100mm 焦段、景别、机位角度、运镜、光圈景深、球面 / 变形光学和运动呈现。机身名称是提示词中的视觉参考，焦段与光圈是成像意图，不保证模型真实模拟硬件。
- 选择参数后点击「应用到镜头槽位」，仅替换镜头中英内容，其他五维保持；原稿先保存历史。再次应用使用替换，避免叠加互相冲突的焦段。鸟瞰景别自动使用俯拍角度。
- 分镜时间轴支持 1–120 秒总时长、最多 20 个时段、0.1 秒步进、连续镜头开关和每段独立中英文动作。添加时段默认追加最多 2 秒；起止时间与动作均可手改。
- 启用时间码后，分段动作替代原动作槽位导出。空档、重叠、越界、非 0.1 秒精度或当前导出语言缺失时，暂停正向复制与 TXT 导出，并指出原因。JSON 仍可下载保存草稿。
- 「AI 编排」使用独立严格 JSON schema，参考当前各维度内容并保持请求的总时长与连续镜头设置。只有验证通过才回填；原来的「智能扩写」继续使用各维度 schema，不会清空时间轴。
- 「10秒猫与纸船」是完整双语示例，含六个连续时段，可直接选择 Muse / 通用后复制测试。Muse 仅为通用格式入口，不假设其具体底层模型能力。
- 时间轴精度表示提示词意图；视频平台中的实际时长仍需手动设置，不能保证模型按 0.1 秒或逐帧执行。
- JSON、历史重载、刷新和 Gist 备份都保留摄影机方案与时间轴；旧版草稿和备份自动补齐默认值。
- 「连接与备份 → 导入备份」可合并此前下载的完整备份 JSON，保留当前草稿。这里接收完整 `video_prompts_backup.json`，不接收单条创作 JSON。文件需小于 3MB；内容会按白名单校验，不导入任何凭证。
- 手机提供浮动「查看成片提示词」入口；输出栏在桌面保持可滚动与吸顶。

## 开始使用

1. 点击「雨夜流浪猫」「沙漠旅人」或「深海水母」载入完整双语示例；也可以直接编辑各维度槽位。
2. 点击常用词标签，或展开维度下方完整词库，自动追加中英文。中英文输入独立编辑，不会将手写中文自动当作英文。
3. 在输出栏选择模型与语言。每个平台按各自的写法导出（见 1.4 更新），格式说明与负向词说明会随平台切换。
4. 复制正向或负向提示词，也可以下载 TXT 或完整创作 JSON。负向提示词保持独立，供支持该字段的平台使用。
5. 编辑暂停 2 秒会自动保存，并持续更新同一条历史；「存入历史」或 Ctrl/Cmd + Enter 会固定为独立一条。草稿会单独缓存，没有正向内容时不产生历史。普通记录保留最近 50 条；收藏置顶且不计入上限。搜索涵盖灵感与所有槽位。

## AI 扩写

在「连接设置」选择快速配置，或填写 OpenAI 兼容 Base URL / 完整 `/chat/completions` 地址、模型与 API Key。快速配置中的模型名称是可编辑的示例，请以账号实际可用模型为准。更换服务预设会清空表单中的旧 API Key，避免误发到新地址。

输入灵感后点击「智能扩写」。各维度扩写与时间轴「AI 编排」分别使用独立的 schema。先从回复中提取 JSON 对象，再严格校验：除「声音」外每个维度都要有非空的 `zh` / `en` 字符串，且不允许多余字段。不合格时自动请求修正一次。解析、网络或校验失败都保留已有内容；扩写过程中若继续编辑，迟到的响应不会覆盖新草稿。支持取消，120 秒自动超时。「输出格式约束」可按接口支持情况选择 json_object 或 json_schema。

所有请求由浏览器直接发出，服务必须允许页面来源的 CORS。`file://` 来源常显示为 `null`，如接口拒绝，可在静态 HTTPS 托管地址使用，或用本地静态服务器：

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory D:/code/work/video-prompt-studio
```

然后在浏览器打开 `http://127.0.0.1:8080`。这只是本地静态预览，不是应用后端。

Ollama 支持 OpenAI 兼容路径 `http://localhost:11434/v1`，本机请求可不填 Key；模型须先在本机可用，服务也需允许浏览器来源。HTTPS 页面调用本机 HTTP 还可能受浏览器混合内容或本地网络权限限制。[Ollama 官方兼容文档](https://docs.ollama.com/api/openai-compatibility)

## Gist 备份

填写具有 `gist` 权限的 PAT，Gist ID 可选：

- 没有 ID：上传通过 `POST /gists` 创建 `public: false` 的 Secret Gist，自动保存返回的 ID。
- 已有 ID：上传通过 `PATCH /gists/{id}` 更新 `video_prompts_backup.json`。
- 拉取：通过 `GET /gists/{id}` 校验并合并历史与词库。记录按 ID 去重，冲突以较新的修改时间为准，删除标记阻止旧备份复活已删除条目。当前编辑草稿保留，界面语言与目标模型从云端恢复。

Secret Gist 不在公开列表中展示，但持有链接的人仍可查看，并非强访问控制的私有存储。备份大于 900 KB 或 GitHub 返回截断文件时会明确拒绝，避免恢复部分损坏数据。[GitHub Gist API 文档](https://docs.github.com/en/rest/gists/gists)

## 凭证与存储隔离

- `vps.studio.v1`：草稿、历史、收藏、词库、界面选项与删除标记。
- `vps.credentials.v1`：API 地址、模型、Key、PAT、Gist ID、输出格式约束。
- 云端与下载的完整备份只通过白名单构建，包含提示词历史、收藏、自定义词库、语言 / 模型选项和删除标记。API 地址、AI 模型配置、API Key、PAT、Gist ID 均不会进入备份。
- 导出额外删除文本中与当前 API Key / PAT 完全相同的字符串。内容以 `textContent` / `value` 渲染，历史、词条与 AI 响应不会作为 HTML 执行。
- API Key 与 PAT 按需求以明文保存在本机 localStorage；请使用可信设备。「清除本机凭证」可移除两个密钥。任何可访问页面的脚本（包括 CDN 依赖）都属于页面的信任范围。
- localStorage 依来源和浏览器隔离；更换本地端口、移动 HTML 文件、换浏览器或清除站点数据，都可能需要重新配置。无痕窗口或存储满额时会显示醒目提醒，下载备份仍可用。
